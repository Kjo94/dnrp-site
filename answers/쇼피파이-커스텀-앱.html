쇼피파이 커스텀 앱은 언제 필요한가요?

작성·검토 디앤알피(DNRP)

마지막 확인 2026-10-04

한 줄 답

쇼피파이 커스텀 앱은 앱 스토어에 있는 앱으로 해결되지 않는 기능이나 외부 시스템 연동이 필요할 때 한 스토어 전용으로 만들어 쓰는 앱입니다.

공개 앱과 무엇이 다른가요?

앱 스토어의 공개 앱은 여러 스토어가 함께 쓰는 반면, 커스텀 앱은 한 스토어의 필요에 맞춰 만들어 그 스토어에서만 씁니다.

어떤 경우에 만드나요?

회사 내부 시스템과의 연동, 특정 업무 규칙에 맞춘 자동화처럼 기존 앱으로 해결되지 않는 경우에 만듭니다.

만들 때 주의할 점은 무엇인가요?

필요한 권한만 요청하고, 접근 토큰을 안전하게 보관하며, 쇼피파이 API 버전이 바뀔 때 유지보수가 필요하다는 점을 미리 고려합니다.

먼저 확인할 것은 무엇인가요?

비슷한 기능의 공개 앱이 있는지, 쇼피파이 기본 기능(자동화 등)으로 해결되는지를 먼저 확인합니다. 만들기보다 쓰는 쪽이 대부분 빠르고 저렴합니다.

누가 만들고 관리하나요?

스토어 관리자 권한이 있는 사람이 관리자 화면에서 앱을 만들고 권한을 정하며, 실제 기능은 개발자가 그 권한으로 구현합니다. 만든 사람이 바뀌어도 운영할 수 있도록 앱이 하는 일, 사용하는 권한, 연결된 외부 시스템을 문서로 남겨 둡니다. 더 이상 쓰지 않는 앱은 삭제해 접근 권한을 정리합니다.

커스텀 앱 만들기 전 확인

  • 같은 기능의 공개 앱을 찾아봤다
  • 쇼피파이 기본 기능으로 안 되는지 확인했다
  • 필요한 권한 범위를 정했다
  • 유지보수 담당을 정했다

관련 서비스는 무엇인가요?

스토어 구축쇼피파이 스토어 구축은 테마 설정부터 상품 등록, 결제·배송 설정까지 판매를 시작할 수 있는 상태로 만드는 작업입니다.운영·성장 관리운영·성장 관리는 오픈 이후 테마 수정, 앱 관리, 오류 대응을 월 단위로 맡는 서비스입니다.
